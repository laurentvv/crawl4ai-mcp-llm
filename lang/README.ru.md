Мощный инструмент для веб-сканирования, который интегрируется с ИИ-ассистентами через MCP (Model Context Protocol). Этот проект позволяет ИИ-ассистентам сканировать веб-сайты, извлекать динамический контент, переходить по ссылкам и напрямую сохранять структурированные файлы в формате Markdown.

## 📋 Возможности

- Нативная интеграция с ИИ-ассистентами через MCP (`crawl`, `crawl_page`, `close_session`, `open_crawl_explorer`, `view_crawl_file`)
- Возврат извлечённого контента в формате Markdown напрямую в ИИ и доступ к сохранённым результатам как MCP-ресурсам (`crawl://results/...`)
- Извлечение и отображение внутренних/внешних ссылок для навигации ИИ
- Сканирование веб-сайтов с настраиваемой глубиной и лимитом страниц, уведомлениями о прогрессе и подробной статистикой
- **Интерактивные MCP Apps (Antigravity / SEP-1865)** — встроены в wheel (Node.js не требуется):
  - **Встроенные карточки** для `crawl` и `crawl_page` (статус, счётчики, просмотр Markdown, фильтрация ссылок, пропущенные страницы)
  - **Crawl4AI Explorer** (`open_crawl_explorer`, боковая панель и полноэкранный режим): пагинация сохранённых результатов, поиск по имени/URL и **полнотекстовый поиск**, **оглавление по страницам** (копирование/прикрепление одной страницы), запуск обхода и управление сессиями
  - **Специальный просмотрщик файлов** (`view_crawl_file` для `.crawlmd` / `.crawl.md`): оглавление по страницам, метаданные и повторное сканирование в один клик
  - 100 % обратная совместимость в текстовом формате для MCP-клиентов без UI

- Обработка ошибок и ненайденных страниц
- **Расширенные возможности сканирования**:
  - **Фильтрация URL по glob-шаблонам**: `include_patterns` и `exclude_patterns` для точного отбора путей
  - **Magic Mode**: эвристики crawl4ai, имитирующие реальный браузер при работе с частью антибот-защит
  - **Целевое извлечение**: получение только необходимых данных с помощью CSS-селекторов
  - **Пользовательский JavaScript** (опционально): выполнение кода перед извлечением (`CRAWL4AI_MCP_ALLOW_JS=true`)
  - **Постоянные сессии**: общий браузер сохраняет cookies и состояние между вызовами (`session_id`)
  - **Поддержка SPA**: ожидание динамических CSS-селекторов или установка явных задержек перед извлечением

## 🚀 Настройка MCP

Самый простой и рекомендуемый способ использования этого инструмента — через `uvx`. Суффикс `@latest` позволяет всегда запускать последнюю опубликованную версию с PyPI.

### Предварительные требования

- [uv](https://github.com/astral-sh/uv), установленный в вашей системе.

### Настройка для ИИ-ассистентов (Claude Desktop, Cline, Antigravity)

Добавьте следующее в файл конфигурации MCP вашего ИИ-ассистента (`cline_mcp_settings.json`, `claude_desktop_config.json` или `mcp_config.json`):

> **Примечание**: Требуется Python 3.12 или 3.13. Рекомендуется указывать `--python 3.13`, особенно на Windows.

```json
{
  "mcpServers": {
    "crawl": {
      "command": "uvx",
      "args": [
        "--python",
        "3.13",
        "crawl4ai-mcp-llm@latest"
      ],
      "disabled": false,
      "autoApprove": [],
      "timeout": 600
    }
  }
}
```

**Claude Code:**

```bash
claude mcp add crawl -s user -- uvx --python 3.13 crawl4ai-mcp-llm@latest
```

**Google Antigravity (плагин с MCP Apps):**

```bash
agy plugin validate ./plugin --strict
agy plugin install ./plugin
```

### Важно: Установка браузера

Скрапер использует Playwright для обработки динамического контента. Установите Chromium один раз после настройки:

```bash
uvx --python 3.13 --from crawl4ai-mcp-llm@latest playwright install chromium
```

## 🖥️ Использование

После настройки вы можете использовать скрапер, попросив вашего ИИ-ассистента выполнить сканирование.

### Примеры использования

- **Одна страница**: «Прочитай https://docs.python.org/3/library/re.html (только эту страницу) и сделай краткое резюме.»
- **Простое сканирование**: «Можешь просканировать сайт example.com и сделать краткое резюме?»
- **Сканирование с параметрами**: «Можешь просканировать https://example.com с глубиной 3 и включить внешние ссылки?»
- **Фильтрация URL**: «Просканируй https://example.com с `include_patterns=['/docs/*']` и `exclude_patterns=['/docs/legacy/*', '*.pdf']`.»
- **Динамический контент**: «Просканируй это React-приложение и дождись загрузки селектора `.main-content`.»
- **Целевое извлечение**: «Просканируй сайт документации, но извлекай только контент, соответствующий CSS-селектору `h1, p.lead`.»
- **Интерактивный Explorer (Antigravity)**: «Открой Crawl4AI Explorer для поиска по сохранённым результатам.»

## 🛠️ Доступные параметры (инструмент `crawl`)

Инструмент `crawl` принимает следующие параметры:

| Параметр | Тип | Описание | Значение по умолчанию |
|-----------|------|-------------|---------------|
| `url` | string | http(s) URL для сканирования (обязательный) | - |
| `max_depth` | integer | Глубина переходов по ссылкам (0-5): 0 = только начальная страница, 1 = её ссылки и т. д. | 2 |
| `max_pages` | integer | Максимальное количество страниц для обхода (1-500) | 50 |
| `include_external` | boolean | Включать внешние ссылки | false |
| `wait_for_selector` | string | CSS-селектор, которого нужно дождаться перед извлечением контента (SPA) | None |
| `return_content` | boolean | Возвращать ли извлечённый контент напрямую в ответе MCP | true |
| `max_content_chars` | integer | Максимальное количество символов содержимого в ответе (1 000-500 000) | 50000 |
| `output_file` | string | Имя Markdown-файла, всегда сохраняется в каталоге результатов | генерируется автоматически |
| `overwrite` | boolean | Разрешить перезапись существующего `output_file` | false |
| `magic` | boolean | Включить magic mode crawl4ai (эвристики антибота) | false |
| `css_selector` | string | Конкретный CSS-селектор для извлечения только целевых элементов со страницы | None |
| `js_code` | string | Пользовательский JavaScript-код перед извлечением (`CRAWL4AI_MCP_ALLOW_JS=true`) | None |
| `session_id` | string | Идентификатор постоянной сессии для сохранения cookies и состояния браузера | None |
| `delay_before_return_html` | number | Задержка в секундах (0-60) перед извлечением HTML (страницы с тяжёлым JS) | None |
| `include_patterns` | array of strings | Переходить только по URL, подходящим под glob-шаблон (напр. `["/docs/*", "*/api/*"]`) | None |
| `exclude_patterns` | array of strings | Пропускать URL, подходящие под glob-шаблон (напр. `["/blog/*", "*.pdf"]`); приоритет выше `include_patterns` | None |
